# Sponsor QR Codes

These files are used by the sponsor page remote update flow.

- `sponsor.json`: remote config loaded by the app
- `wechat.png`: WeChat Pay QR code
- `alipay.jpg`: Alipay QR code

To replace QR codes after release, update the image files here and keep the same filenames. The app will continue using bundled QR codes when the remote config is unavailable.
