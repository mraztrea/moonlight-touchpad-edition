# Moonlight Touchpad Edition Release Notes

## v0.1.4-touchpad

## 中文说明

Moonlight Touchpad Edition 是 Moonlight Android 的非官方修改版，主要优化安卓平板键盘和触摸板体验。本项目与官方 Moonlight 项目无隶属关系。

### 主要特性

- 支持小米 Pad 6 Max 14 原厂磁吸键盘和蓝牙键盘触摸板输入
- 支持触摸板相对移动鼠标指针，并可调节指针速度
- 默认使用更适合平板的分辨率和低延迟帧同步策略
- 使用独立包名 `com.limelight.touchpadedition`，可与官方 Moonlight 共存安装

### 新增手势

- 单指移动：移动串流电脑上的鼠标指针
- 单指轻点：鼠标左键单击
- 按下触摸板：鼠标左键单击或左键按住
- 双击且第二下按住：鼠标左键按住并拖拽
- 双指轻点：鼠标右键
- 双指上下滑动：鼠标滚轮纵向滚动
- 双指左右滑动：鼠标横向滚动
- 双指捏合：通过 Ctrl + 鼠标滚轮模拟缩放
- 三指轻点：鼠标中键
- 三指左右滑动：Alt + Tab 任务切换
- 三指上滑：任务视图
- 三指下滑：显示桌面

## English Description

Moonlight Touchpad Edition is an unofficial fork of Moonlight Android focused on Android tablet keyboard and touchpad support. This project is not affiliated with the official Moonlight project.

### Highlights

- Handles Xiaomi Pad 6 Max 14 magnetic keyboard and Bluetooth keyboard touchpad input
- Supports relative touchpad cursor movement with configurable pointer speed
- Uses tablet-friendly default resolution and low-latency frame pacing
- Uses the independent package name `com.limelight.touchpadedition`, so it can be installed alongside official Moonlight

### Added Gestures

- One-finger movement: move the host mouse pointer
- One-finger tap: left click
- Physical touchpad press: left click or left-button hold
- Double tap with second tap held: left-button hold and drag
- Two-finger tap: right click
- Two-finger vertical scroll: mouse wheel vertical scrolling
- Two-finger horizontal scroll: mouse wheel horizontal scrolling
- Two-finger pinch: zoom using Ctrl + mouse wheel
- Three-finger tap: middle click
- Three-finger left/right swipe: Alt + Tab task switching
- Three-finger up swipe: task view
- Three-finger down swipe: show desktop
